## Typescript Journey

In this assignment, I worked on TypeScript from basic to advanced topics, such as union types and tuples. I also worked on object-oriented programming with access modifiers. I solved problems, and along with that, It includes the problems I solved.

## What I Have Covered So Far
- TypeScript Basics and Advanced Types

I learned the basic types and how to add types to variables.

- Object-Oriented Programming

I learned how to make classes and constructors. I used four access modifiers: `public`, `private`, `protected`, and `readonly`. They decide who can use or change the data in a class. I also used a shortcut called parameter properties, and I used `extends` to make one class from another class.
